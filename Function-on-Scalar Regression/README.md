# Neural Networks for Function-on-Scalar Regression

This directory contains the dataset and R implementation for the neural netowrk-based function-on-scalar (FoS) regression models, including NNBB, NNSS, NNBR & NNSR, introduced in the manuscript "[Neural Networks for Scalar Input and Functional Output](https://doi.org/10.1007/s11222-023-10287-3)".

### Files

- `asfr.RData`: The age-specific fertility rate (ASFR) data set.
- `FoS_Functions.R`: The helper functions file, which needs to be sourced.
- `FoS_demo.R`: Code for reproducing the numerical experiment on the age-specific fertility rate (ASFR) data set using the NN-based models (NNBB, NNSS, NNBR & NNSR) and the tranditional approaches (FoS linear and FAMM).
